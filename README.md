# ecommerce-test-framework

Project structure:

- `src/pages` - Page Object classes for UI automation
- `src/api` - API client and service classes
- `src/fixtures` - Custom Playwright fixtures and test state
- `src/utils` - Helpers and test data generators
- `tests/ui` - UI test specs
- `tests/api` - API test specs
- `tests/hybrid` - Combined UI + API tests
- `load-tests` - k6 scripts
